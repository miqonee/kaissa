# «Каисса» — Командный шахматный клуб 2×2

Полноценная онлайн-платформа для командных шахматных баталий:
1. **Багхаус (Bughouse)** — игра на двух досках парами. Сбитые фигуры попадают в карман напарника и выставляются на его доску дропом.
2. **2×2 на одной доске** — игра вчетвером на одной доске с поочерёдным чередованием ходов внутри команды (Слот 1 → Слот 2 → Слот 1).

Дизайн выполнен в эстетике шахматного клуба Lichess с полноценной **тёмной** (по умолчанию) и **светлой** темами, деревянными досками и оригинальными векторными фигурами cburnett.

---

## ⚡ Быстрый запуск (Docker Compose)

```bash
# 1. Скопировать и настроить переменные окружения
cp .env.example .env

# В .env можно указать логины администраторов:
# ADMIN_USERNAMES=admin,ivan1

# 2. Сборка и запуск контейнеров
docker compose up -d --build

# 3. Проверка статуса
docker compose ps
```

Приложение доступно по адресу: **`http://localhost:8080`**

## 🎮 Игровые механики

### 1. Багхаус (2 доски)
- Играют две доски одновременно. Партнёры по команде сидят за противоположными цветами (Команда 1: белые на доске 1 + чёрные на доске 2).
- Каждая сбитая фигура меняет цвет и падает в «карман» напарника.
- В свой ход вместо обычного перемещения фигуры игрок может **выставить (дропнуть)** любую фигуру из кармана на свободное поле.
- Пешку нельзя дропать на 1-ю и 8-ю горизонтали.
- Мат, сдача или истечение времени на любой из двух досок немедленно завершают весь командный матч победой соперников.

### 2. Матч 2×2 (одна доска)
- На одной доске сражаются две команды по два человека (Белые vs Чёрные).
- Внутри команды ходы строго чередуются: `Белый 1` → `Чёрный 1` → `Белый 2` → `Чёрный 2` → `Белый 1`…
- В интерфейсе над доской явно подсвечивается текущий ход каждого из 4 участников, а также показывается, кто ходит следующим.
- Пат считается победой стороны, объявившей его (в клубе ничьих нет).

## 🏆 Рейтинг (Elo) и балансировка
- Начальный рейтинг игрока: **1200**, коэффициент **K=32**.
- При старте лобби все 4 игрока автоматически сортируются по рейтингу и распределяются по схеме «змейка» (**1+4 против 2+3**), что гарантирует максимальный баланс сил.
- После партии рейтинг участников пересчитывается с учётом силы команды соперников и сохраняется в истории.

## 🔍 Архив, PGN и анализ на Lichess
- Вкладка **«Архив партий»** содержит историю всех завершённых игр клуба.
- Для любой партии доступно:
  - **Интерактивный плеер ходов** (с разбором по полуходам).
  - **Скачивание PGN** (сохраняются имена игроков, результат, время и дропы в нотации `P@h6`).
  - **Кнопка «Анализ на Lichess ↗»**: партия автоматически отправляется в движок Stockfish на lichess.org в один клик.

## 🛡️ Панель администратора (`/admin`)
- Пользователи, указанные в `ADMIN_USERNAMES` в файле `.env`, автоматически получают права администратора при старте сервера.
- Возможности админ-панели:
  - Просмотр всех зарегистрированных игроков, их онлайн-статуса и статистики.
  - Удаление тестовых аккаунтов (с каскадным удалением их партий).
  - Сброс рейтинга игрока на базовые 1200 пунктов.
  - Назначение других игроков администраторами.
